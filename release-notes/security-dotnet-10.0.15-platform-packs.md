Linux x86 and FreeBSD runtime packs are rebuilt from the .NET 10.0.15 servicing sources. Source-build package metadata is normalized to the .NET 10.0.15 release for both targets. This supersedes the earlier release note's platform-pack limitation: both community-supported targets now ship the current .NET 10 security patch.
