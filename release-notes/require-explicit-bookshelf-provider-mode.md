action: Pass an explicit provider mode; native Hardcover requires a supported versioned image tag.

BookshelfNG migration previews and applies now require an explicit provider mode. Native Hardcover mode requires a versioned ChaptarrNG image at v0.9.978 or newer, preventing unsupported images from treating numeric IDs as Goodreads.
